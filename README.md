# Doc AI Agent 🤖

> An AI-powered agent that searches through technical documentation and answers questions with accurate, sourced responses.

---

## Overview

Finding relevant information in large technical documentation bases is time-consuming. **Doc AI Agent** solves this by combining a fast full-text search engine with a conversational AI agent — you ask a question in natural language, and the agent retrieves the most relevant documents and returns a precise, grounded answer.

**Key highlights:**
- Natural language question answering over your own documentation
- Fast keyword-based search with `minsearch` (no vector DB required)
- AI-powered responses generated by a Groq-hosted LLM via Pydantic AI
- Clean web interface built with Streamlit

## Features

- 🔍 **Full-text search** over indexed technical documents using `minsearch`
- 🤖 **AI agent** built with Pydantic AI, powered by Groq (fast LLM inference)
- 🌐 **Streamlit web interface** — no CLI required
- 📄 **Source references** — responses include the source documents used
- ⚡ **Lightweight** — no vector database or embedding model needed

## Installation

### Prerequisites

- Python 3.10+
- A [Groq API key](https://console.groq.com/)

### Setup

```bash
# Clone the repository
git clone https://github.com/bidyhandrianarison/doc-ai-agent.git
cd doc-ai-agent

# Create and activate a virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Set your API key
export GROQ_API_KEY=your_groq_api_key_here
```

---

## Usage

### Run the data pipeline

Index your documents before running the agent:

```bash
python pipeline/ingest.py
```

### Launch the web interface

```bash
streamlit run app.py
```

Then open [http://localhost:8501](http://localhost:8501) in your browser.

## Evaluations

> ⚠️ Evaluations are currently in progress.

The evaluation pipeline is set up in `eval/`. It uses an LLM-generated Q&A dataset to measure the quality of the agent's answers.

Planned metrics:
- **Hit Rate** — does the correct document appear in the top results?
- **MRR** (Mean Reciprocal Rank) — how highly is the correct document ranked?
- **Answer relevance** — LLM-as-judge scoring of the final response

*Results will be added here once evaluation is complete.*
